# Community code of conduct

QueueTwin aims to be a respectful, inclusive space for learning and contributing. We welcome contributors regardless of experience, background or location.

We expect constructive technical discussion, empathy, evidence-based disagreement and respect for boundaries. Harassment, discrimination, intimidation, doxxing and the sharing of private data are not acceptable.

Maintainers may edit or remove inappropriate contributions and limit participation when necessary. Report concerns privately through GitHub's available maintainer contact mechanisms.
