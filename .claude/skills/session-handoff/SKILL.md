---
name: session-handoff
description: Produce a factual, concise repository handoff so another human or AI agent can continue safely.
---

1. Inspect `git status`, current code changes and `docs/ai/TASKS.md`.
2. Record completed work and exact verification commands/results in `docs/ai/HANDOFF.md`.
3. List uncommitted files, known defects, ambiguous decisions and the next bounded task.
4. Update `docs/ai/DECISIONS.md` only if an explicit decision was accepted and documented.
5. Never report external publication, CI success or browser verification without actual evidence.
